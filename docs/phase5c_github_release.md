## HunyuanOCR-ncnn v0.1.0 CPU Runtime

First public binary release of HunyuanOCR-ncnn.

This release contains only the C++ runtime, OCR CLI, headers, CMake package,
README, NOTICE, and license files. It does **not** include HunyuanOCR model
weights or converted ncnn runtime artifacts.

Users must obtain `tencent/HunyuanOCR` separately and comply with the Tencent
Hunyuan Community License Agreement before downloading, converting,
distributing, or using model files. Converted runtime artifacts can be
reproduced from a local HuggingFace model directory with the repository
pipeline documented in `README.md`.

### Validation

The packages are based on the Phase 4L dual-platform offline release gate:

- Linux CTest suites: smoke, dynamic, real-png, real-jpeg, cache-budgets,
  error-paths
- Windows/MSVC CTest suites: smoke, dynamic, real-png, real-jpeg,
  cache-budgets, error-paths
- Linux installed package extraction and OCR passed in packed and unpacked
  modes
- Windows ZIP extraction and OCR passed in packed and unpacked modes

The model directory used for validation was regenerated by Phase 4K from a
local `tencent/HunyuanOCR` HuggingFace model directory. Model weights and
converted model artifacts are intentionally not bundled in this GitHub Release.
